# 02 · 编辑评审与改进建议

> 站位：**儿童绘本编辑 + 3-6 岁亲子共读老用户** 双视角。
> 评审目标：让这本书读起来"像一本真的童书"，而不是"AI 拼出来的素材"。
>
> 每条建议分三档：
> - 🔴 **强烈建议改**：不改会影响阅读体验或印刷成品
> - 🟡 **建议改**：改了更好，不改也不至于翻车
> - 🟢 **可选**：纯锦上添花

---

## 一、文字层面

### 🔴 1.1 P3 双引号嵌套问题

**原文：** 她们来到迷雾森林，子琪牵着兔子，心想："我很勇敢！"

**问题：**
- 整本书的页面文字本身在排版时通常会被引号或圆角框包住，再嵌一层中文双引号 `""`，视觉上会出现"引号里套引号"的混乱。
- "心想"+ 直接引语在儿童语境里也偏成人化，5 岁孩子更容易接住具体动作。

**建议改为（任选其一）：**
- A：迷雾森林里又黑又静，子琪悄悄握紧兔子的手——我很勇敢。（30 字，破折号自白）
- B：迷雾森林好黑呀，子琪深吸一口气，对自己说：我很勇敢！（25 字，去掉外层叙述引号）

### 🟡 1.2 兔子全程没有名字

**问题：** 全书 11 处提到兔子，称呼在"云朵兔子"和"兔子"之间反复横跳，孩子记不住一个"具体的伙伴"。绘本里的动物伙伴**有名字** 是建立情感投射的关键（像吉米的"小熊"、宫西达也的"小恐龙"都有名字）。

**建议：** 给兔子起名 **"小棉花"**（呼应它"毛茸茸""像云朵"的设定，5 岁孩子一遍就能记住）。
- 第一次出场（P1）正式介绍："这只云朵兔子叫小棉花。"
- 之后全部用"小棉花"。

### 🟡 1.3 P10 父母出场突兀

**问题：** 全书 P1-P9 都是子琪 + 小棉花的二人冒险，P10 突然蹦出爸爸妈妈给一个拥抱，叙事没有铺垫。

**建议：**
- 在 P1 加一句"爸爸妈妈说，这是给你的六一礼物"作为情感锚点；或
- P10 改成"妈妈轻轻敲门，问她做了什么梦"——把父母放在"现实端"，与冒险的"梦幻端"形成温暖回归。

### 🟢 1.4 祝福页日期已过期

**原文：** `2024年6月1日`
**今天：** 2026年5月29日，距离今年六一只剩 3 天。
**建议：** 改为 `2026年6月1日`。

### 🟢 1.5 P10 收尾略说教

**原文：** 回到家，子琪知道，爸爸妈妈的爱和勇气，会永远陪着她。

**问题：** "知道...会永远陪着她"是叙述者口吻在替孩子下结论，3-6 岁绘本更喜欢用**具体感官** 收尾。

**建议改为：** 回到家，子琪抱着小棉花睡着了，胸口暖暖的，做了一个甜甜的梦。（30 字）

## 二、故事节奏层面

### 🔴 2.1 P3 与 P4 主题重叠

**问题：**
- P3 文案是"我很勇敢"（情感勇气）
- P4 文案是"用自信的魔法棒"（自信）
- "勇敢"和"自信"在 5 岁孩子的认知里几乎是同一件事，连排两页等于在原地踏步。

**更严重的问题：** 魔法棒"自信地变出彩虹桥"——子琪还**没经历过任何挫折**，自信从哪来？童书的成长弧需要"害怕 → 努力 → 成功"的小三段，而不是"我会魔法 → 通过"。

**建议改造：**
- P3 改为**"害怕但还是往前走"**（情感勇气的真实样貌）：迷雾森林好黑呀，子琪有点害怕，但她紧紧牵着小棉花，一步一步往前走。
- P4 改为**"用想象力解决问题"**（创造力 / 思维勇敢）：子琪发现一束星光，她跟着星光画呀画，画出一座彩虹桥。

这样两页就有了"克服害怕 → 主动创造"的递进，而且都在演"勇敢"的不同侧面。

### 🟡 2.2 主线"勇气星星"在中段失踪

**问题：** 兔子开篇说"勇气星星丢了"，但 P3-P8 的子琪都在做别的事（克服迷雾、分享水、陪伴云朵宝宝），到 P9 突然在山顶找到星星。**主线和支线断了。**

**建议改造（不增加页数）：**
- 让每完成一个善举，**一颗小星星**自动从子琪身上飞起，飘向远方。这是视觉伏笔。
- P9 揭示："原来勇气星星不是一颗——是你一路点亮的所有小星星汇成的。"

这样 P3-P8 的所有善举都被串起来了，故事一下从"流水账冒险"升级成"成长寓言"。

### 🟢 2.3 起承转合页数比例

| 段落 | 原方案页数 | 建议 |
|------|------------|------|
| 起 | P1-P2（2页） | 保留 |
| 承 | P3-P6（4页） | 保留 |
| 转 | P7-P8（2页） | 保留 |
| 合 | P9-P10（2页） | 保留，但 P9 增加"集星"高光时刻 |

整体节奏其实没问题，只要把 2.1 + 2.2 修了，就立得住。

## 三、画面构图层面

### 🔴 3.1 警告：每页都"子琪+兔子居中"会很无聊

**问题：** 原方案 11 页（封面+10 内页）的提示词，主体描述几乎都是"子琪和兔子在 XX 场景"，没有视角变化。绘本翻页的快感，**一半来自构图节奏**。

**建议：用三种镜头节奏交替：**

| 页 | 建议镜头 | 理由 |
|----|----------|------|
| 封面 | 中近景 · 正脸特写 | 让小读者一眼记住主角 |
| P1 | 中景 · 室内斜视角 | 展现温馨日常 |
| P2 | **大全景 · 俯视云海** | 与 P1 封闭室内强烈对比，制造翻页惊喜 |
| P3 | **仰视 · 树影压迫** | 表达"森林好高好黑"的孩子视角 |
| P4 | 平视 · 透视引导线 | 彩虹桥延伸到远方，给希望感 |
| P5 | **近景 · 小手特写** | 倒水的善意聚焦在手部 |
| P6 | 中景 · 放射构图 | 树花绽放呈花苞放射状 |
| P7 | 近景 · 拥抱特写 | 情感最浓的瞬间用最近的镜头 |
| P8 | 中景 · 三角构图 | 子琪/小棉花/云朵宝宝形成稳定三角 |
| P9 | **仰视 · 满天星光** | 山顶夜空的辽阔感 |
| P10 | 中景 · 暖光室内 | 回到 P1 的房间，光线变暖呼应 |

### 🟡 3.2 白色纱裙在水彩里容易"消失"

**问题：** 白色纱裙 + 白色云朵 + 浅色背景 → 水彩晕染下，主角会糊进背景里。

**建议：** 在裙摆给一点辨识度——
- 浅蓝色/淡粉色腰带 或
- 裙边一圈极淡的星星刺绣 或
- 裙摆下摆带一点点天蓝色描边

这是绘本师常用的小技巧，既保留"白色公主裙"的设定，又不让主角融化。

### 🟢 3.3 兔子小棉花的造型也要"锚定"

建议给小棉花一个**记忆点**：比如脖子上系一根浅蓝色丝带、或左耳尖一缕粉色绒毛。这样即使 AI 不同次生成有差异，**只要锚点对，孩子就认得是同一只兔子**。

## 四、提示词技术层面

### 🔴 4.1 "请参考 image_0.png"对很多 AI 模型不生效

**问题：** Midjourney 用 `--cref` + 图片 URL；即梦/豆包要在它的界面单独上传参考图；Stable Diffusion 用 IPAdapter / Reference ControlNet；GPT-4o Image 是直接附图——**没有任何一个模型会读懂"请参考 image_0.png"这句中文指令**。

**建议：** 把这句话从 prompt 里**删掉**，改成在生成时通过工具的"参考图"通道上传。具体见 `04-生图提示词-修订版.md` 的工具适配表。

### 🔴 4.2 "在画面中加入中文文字"基本会翻车

**问题：** 截至 2026 年，**所有主流图模生成中文长句仍然不可靠**——常见乱码、错别字、笔画错乱。绘本印刷品对文字要求 100% 准确。

**强烈建议：**
- AI 只负责**画图**，每页底部留 **20%-25% 的纯净空白**
- 文字用 InDesign / Affinity Publisher / Word / Canva **后期排版**贴上去
- 字体推荐：**站酷快乐体 / 鸿雷板书 / 字魂童心体**（儿童感、可商用免费的几款）

### 🟡 4.3 角色一致性的实操技巧

让同一个孩子贯穿全书的几个**已知有效**做法：
1. **Midjourney**：用 `--cref` 锁脸，配合 `--cw 100` 强权重；首图先生成一张"标准像"，后面所有图都参考这张。
2. **GPT-4o / Nano Banana**：每次生图都把首张定稿图 + 文字描述同时发，要求"保持人物外观与第一张一致"。
3. **即梦 / 豆包**：用"角色一致性"或"参考图"功能，必须用同一张参考图。
4. **通用兜底**：先生成 1 张"角色三视图"（正面/侧面/背面）当 model sheet，后面每张图都让 AI 参考三视图。

### 🟢 4.4 负面提示词补几个常用项

原方案的负面词已经很全，可以再加：
- `text, watermark, signature, multiple children, twins, duplicate face, blurred face, deformed hands`
- 中文版：`不要文字、不要水印、不要签名、不要双胞胎、不要重复人脸、不要模糊脸部、不要变形的手`

## 五、商业 / 印刷层面（提前预警）

### 🟡 5.1 是否要量产销售？

原方案有"商品详情页简介"这一栏，看起来像是要上架卖。但内容是"献给华子琪"的高度私人化——**这两个定位是冲突的**。

请确认：
- **A. 私房礼物：** 删掉"商品详情页简介"那栏，专心做一本独一无二的礼物
- **B. 量产模板：** 把"子琪"换成可替换变量 `{孩子姓名}`，做成"姓名定制绘本"模板，可以批量卖

我的推荐是 **A**，因为故事里的情感锚点（爸爸妈妈、5 岁半、六一）都很私人，硬拗成模板会显得空洞。

### 🟢 5.2 印刷规格预案

等图出来后再确定，但可以提前选：
- 开本：**21×21cm 方本**（最经典的儿童绘本开本，孩子小手好握）
- 装订：**精装硬壳**（送礼级别）或 **骑马钉**（成本低）
- 纸张：内页 **128g 哑粉纸** 或 **157g 铜版纸**
- 出血：上下左右各 3mm
- 色彩：**CMYK** 模式（AI 生图都是 RGB，印前要转 CMYK 并校色，**否则成品会偏暗**）
- 数量：私房礼物建议印 **3-5 本**（孩子一本、爷爷奶奶外公外婆各一本）
