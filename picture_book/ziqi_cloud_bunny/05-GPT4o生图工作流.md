# 05 · GPT-4o Image 生图工作流（傻瓜式 13 步）

> 工具：ChatGPT Plus / Pro 订阅版的 **GPT-4o Image**
> 原则：**全程一个对话窗口**（不要新开窗口，否则失去角色记忆）
> 总计：1 张角色三视图 + 11 张内页 + 1 张祝福页 = **13 次生图**
> 预计耗时：60–90 分钟（含挑图、重生、保存）

---

## 开工前清单

- [ ] 已开通 ChatGPT Plus（$20/月）或 Pro 订阅
- [ ] 已准备好 `image_0.png`（子琪的参考照片）
- [ ] 已新建一个收图文件夹，比如 `桌面/子琪绘本/`
- [ ] 网络稳定（GPT-4o Image 出图慢的时候单张 1–2 分钟）
- [ ] **打开 `06-生图进度跟踪.md`**，每出一张就在那里打勾

---

## 重要的工作原则（一定要看）

### 原则 1：**永远在同一个对话窗口里出完所有 13 张**
GPT-4o 的角色一致性来自"对话上下文记忆"。新开窗口 = 角色重置，画风也会跑偏。

### 原则 2：**让 AI 画图，让你自己排文字**
即使提示词里写了"画上中文文字"，GPT-4o 仍会乱码或写错字。**所有提示词都明确说"不要在图中加任何文字"**，文字最后用 Word/Canva/InDesign 排上去。

### 原则 3：**先三视图，后场景**
第一张必须是"角色三视图（model sheet）"，这是后续 12 张的视觉锚点。**没有这一步直接画封面，后面会越画越走样。**

### 原则 4：**每张图 1–3 次重生 = 正常，超过 3 次换 prompt**
GPT-4o 不是抽卡机，如果连续 3 次出来都不对，说明提示词描述有歧义，需要回来调措辞，而不是傻乎乎硬抽。

### 原则 5：**及时保存原图**
ChatGPT 的图会过期。**每张满意的图右键"另存为"立刻存到本地**，文件名建议 `P00_角色三视图.png` / `P01_礼物.png` / ... / `P11_回家.png` / `P12_祝福页.png`。

## 第 0 步 · 开场设定（一次性，奠定整个对话基调）

> 操作：新建一个 ChatGPT 对话，**附上 `image_0.png`**，然后粘贴下面整段：

```
你好，我们要一起为我女儿做一本 12 页的私人绘本，主角是图中这个 5 岁半的中国小女孩，她叫子琪。

绘本风格要求：
- 温暖的水彩童书插画风格
- 柔和的自然光
- 低饱和但明亮的色彩
- 梦幻但有真实感
- 适合 3-6 岁儿童阅读
- 类似宫崎骏 + 几米 + 经典欧美水彩绘本的混合质感

主角设定（请严格按照参考照片）：
- 5 岁半中国小女孩，名字叫子琪
- 黑色头发，梳两个低低的小辫子
- 发际线戴一个珍珠头饰
- 圆润可爱的脸型，圆眼睛
- 笑容灿烂、活泼自信
- 全书统一服装：白色多层纱质公主裙 + 浅蓝色腰带 + 白色凉鞋

伙伴角色：
- 一只名叫"小棉花"的云朵兔子
- 圆润、毛茸茸、像一朵云那么蓬松
- 白色为主，脖子系一根浅蓝色丝带
- 表情聪明可爱，不过度拟人

接下来我会一页一页让你画，请记住：
1. 全程保持子琪和小棉花的外观完全一致（参考第一张三视图）
2. 全程保持水彩童书画风一致
3. 不要在任何图中生成中文字、英文字、水印、签名或 logo
4. 每张图都给底部留 25% 左右的纯净空白，方便我后期排版加文字

如果都明白了，请回复"明白"，然后我会让你画第一张：角色三视图。
```

> ⏳ 等 GPT 回复"明白"或类似确认。如果它直接画图了，跟一句"先不画，我让你画再画，先确认你理解了上面所有要求"。

## 第 1 步 · 角色三视图（最重要的一张，慢工出细活）

> 操作：发下面这段。**这张是后面所有图的"圣经"，不满意必须重生。**

```
请画一张角色三视图（character reference sheet / model sheet）：

画面构成：在同一张图中并排展示
- 左侧：子琪的全身正面立绘
- 中间：子琪的全身侧面立绘
- 右侧：子琪和小棉花并肩的全身正面立绘

要求：
- 温暖水彩童书风格
- 简单的浅色背景（米色或淡米黄）
- 三个姿势的子琪外观必须完全一致：黑色双低辫、珍珠头饰、白色多层纱裙、浅蓝腰带、白色凉鞋、圆脸、自信微笑
- 小棉花：圆滚滚白色云朵兔子，浅蓝色丝带
- 不要任何文字、不要标签、不要箭头标注
- 1:1 正方形画幅
- 高清、清晰、可作为后续插画的参考
```

### 验收标准（必须全部 √）

- [ ] 三个子琪的脸完全一样
- [ ] 双辫子位置一致（低位、对称）
- [ ] 珍珠头饰看得清
- [ ] 服装颜色和款式三个姿势一致
- [ ] 小棉花蓬松、圆润、可爱（不是写实兔子）
- [ ] 没有任何乱码文字
- [ ] 整体画风温暖治愈

### 如果不通过

发这段：
```
脸不太一致 / 服装不一致 / [其它具体问题]，请重新画一遍三视图，
保持温暖水彩童书风格，三个姿势的子琪外观必须完全相同。
```

> ✅ **三视图通过后，立刻右键保存为 `P00_角色三视图.png`**，这是您的"角色身份证"。

## 第 2–13 步 · 12 张内页（每张一段，按顺序粘贴）

> 每发一段之前，**确认上一张图您已经满意并保存**。

## 排版与印刷收尾（图全出完后）

1. **本地建好 13 个文件**：`P00_角色三视图.png` 留底，`P01_封面.png` 到 `P12_祝福页.png` 共 12 张用于排版。
2. **统一裁切**：所有图按 1:1 裁切，留 3mm 出血。
3. **CMYK 转换**：用 Photoshop 把所有图从 RGB 转 CMYK，**饱和度+5、亮度+3** 补偿印刷损失（不补偿成品会偏暗）。
4. **排版加文字**：用 InDesign / Affinity Publisher / Canva / Word，每页底部 25% 留白处加上 `03-逐页文案-修订版.md` 的对应文字。字体推荐：

   - **书名**：方正喵呜体 / 站酷文艺体
