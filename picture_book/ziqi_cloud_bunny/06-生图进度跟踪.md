- [ ] **双辫子**：位置始终一致？没有突然变成单马尾或散发？
- [ ] **珍珠头饰**：每张都看得到？没有消失？

- [ ] **小棉花**：始终是同一只兔子，圆润度一致，浅蓝丝带还在？

- [ ] **集星伏笔**：P05 / P07 / P09 / P10 的星星视觉链条是否连贯？
- [ ] **房间呼应**：P02 和 P11 是不是同一个房间？
