## 工作流建议

1. **先看 02**：决定哪些建议采纳、哪些保留原案。
2. **再看 03 / 04**：这是按「全部采纳建议」写出的版本，您可以直接用，也可以挑着合并回原案。
3. **进入生图阶段**：把 04 的提示词喂给目标 AI 工具（Midjourney / 即梦 / GPT-4o Image / Nano Banana 等），文字部分**不要**让 AI 生成，最后用 InDesign / Word / Canva 单独排版上去——这是目前所有图模都还做不好中文长句的现实。
4. **印刷前**：补一份印刷规范文档（开本、出血、CMYK、纸张），这部分等图出来后再做。

## 核心约束（贯穿全本）

- 主角原型：华子琪，5 岁半，参考 `image_0.png`
- 角色锚点：黑色双低辫 + 珍珠头饰 + 圆脸 + 自信笑容 + 白色纱裙
- 情绪关键词：陪伴、勇敢、被爱、梦想、成长、分享、安全感
- 画风：温暖水彩童书、柔和自然光、低饱和明亮色、梦幻但真实
- 适读年龄：3–6 岁
- 总页数：封面 + 10 内页 + 1 祝福页 = 12 页
