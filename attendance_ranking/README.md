# 合肥基地氛围排名自动化工具

本工具用于自动计算合肥基地员工的考勤/工时排名，替代原有的Excel公式计算方式。

## 功能说明

- 读取现有Excel中的参数设置、花名册、源数据
- 自动计算个人平均工时排名
- 自动计算部门平均工时排名（职能/销售分开排名）
- 生成格式化输出Excel，包含条件格式、图表、月度报告

## 依赖安装

```bash
pip install openpyxl pandas
```

## 使用方法

```bash
# 使用默认输入输出路径
python3 attendance_ranking/ranking.py

# 指定输入输出文件
python3 attendance_ranking/ranking.py -i "合肥基地氛围排名_严格排查修复_全名单个人排名.xlsx" -o "输出文件.xlsx"
```

## 参数说明

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| --input | -i | 合肥基地氛围排名_严格排查修复_全名单个人排名.xlsx | 输入Excel路径 |
| --output | -o | 合肥基地氛围排名_输出.xlsx | 输出Excel路径 |

## 输出文件说明

输出Excel包含4个Sheet：

1. **个人排名** - 全部人员按平均时长降序排名，包含条件格式（前10绿色，后10红色）
2. **部门排名** - 职能部门和销售部门分别排名，附带柱状图
3. **月度排名** - 精简版月度报告，可直接用于发送
4. **检查项** - 数据质量检查项目

## 计算逻辑

1. 日期分类：排除日(跳过) / 工作日 / 普通周六 / 周日
2. 工作日统计：工时 >= 6小时的记录计入有效天数和工作日总时长
3. 周六统计：不设阈值，所有周六工时都计入
4. 平均时长 = (工作日总时长 / 有效天数) + (周六总时长 / 工作日天数)
5. 部门排名：仅统计"是否统计=统计"且平均时长>0的人员
